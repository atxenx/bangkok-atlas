# Bangkok Atlas frontend

The Next.js frontend serves the landing page and interactive Bangkok map. See the [project README](../README.md#run-locally) for the full setup, including the FastAPI backend and bundled data.

Run these commands from this directory once the backend is running.

```bash
npm ci
npm run dev
```

Open [http://localhost:3000/explore](http://localhost:3000/explore). For a production build, use `npm run build` followed by `npm start`.
